In text

Every letter is drawn as a single centre line and expanded to an outline at build time, so the face keeps one stroke thickness everywhere: no thick-and-thin, no corners, no counters cut by hand. The round terminals come from the stroke itself. Set it large. It is a display face, and it gets quiet below 16 px.

Construction

Centre lines on the 200-unit design grid. Blue rules mark the x-height and the baseline.

Install and use

@font-face {
  font-family: "Arclight";
  src: url("Arclight-Regular.woff2") format("woff2");
  font-weight: 400;
  font-display: swap;
}
/* repeat for 300 (Light) and 700 (Bold) */

h1 { font-family: "Arclight", sans-serif; letter-spacing: .05em; }
